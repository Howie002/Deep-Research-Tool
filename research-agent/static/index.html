Search Backend

Getting a LangSearch API key

  1. Go to langsearch.com/dashboard
  2. Sign up for a free account
  3. Copy your API key from the Dashboard page
  4. Paste it below — free tier includes 1 000 searches/month

Getting a Brave Search API key

  1. Go to brave.com/search/api
  2. Click Get started for free and create an account
  3. Subscribe to the Free tier (2 000 queries/month) or a paid plan
  4. Navigate to API Keys and create a new key
  5. Paste the key (starts with BSA) below

Getting a SerpAPI key

  1. Go to serpapi.com/users/sign_up
  2. Create a free account (100 searches/month included)
  3. From your dashboard, copy the API key shown under Your Private API Key
  4. Paste it below
